# Architecture Decision Records (ADRs)

Este diretório registra as decisões arquiteturais fundamentais adotadas no projeto **Zenith**.

## O que é um ADR?
Um Architecture Decision Record captura uma decisão técnica significativa, incluindo o contexto no qual ela foi tomada, as alternativas consideradas e suas consequências.

## Convenção de Nomenclatura
- Arquivos: `NNN-titulo-em-kebab-case.md` (com numeração de 3 dígitos, ex: `002-autenticacao-session.md`).
- Status possíveis: `Proposto`, `Aceito`, `Depreciado`, `Substituído por [ADR-XXX]`.
